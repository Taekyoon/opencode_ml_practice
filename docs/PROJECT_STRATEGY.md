### Phase 1: 기반 다지기

**목표:** 프로젝트 구조 표준화 + 에러 처리

| 작업 | 상세 | 산출물 |
|------|------|--------|
| 패키지 구조화 | `__init__.py`, `pyproject.toml` 추가 | 설치 가능 패키지 |
| CLI 구축 | `main.py`로 전체 파이프라인 실행 | `python -m src run` |
| 에러 처리 | 각 모듈에 try/except + 입력 검증 | 방어적 프로그래밍 |
| 설정 분리 | `config.yaml`로 하이퍼파라미터 관리 | 재현 가능한 실험 |
| `.gitignore` | `__pycache__/`, `plots/`, `*.pyc` 등 | Git 관리 |

**구조 변화:**
```
semiconductor_failure_prediction/
├── src/
│   ├── __init__.py          # 신규
│   ├── main.py              # 신규 (CLI 진입점)
│   ├── config.py            # 신규 (설정 관리)
│   ├── data_generation.py
│   ├── preprocessing.py
│   ├── model.py
│   └── evaluation.py
├── config.yaml              # 신규 (하이퍼파라미터)
├── pyproject.toml           # 신규
├── .gitignore               # 신규
└── tests/                   # 신규
```

### Phase 2: 코드 품질 고도화

**목표:** 타입 힌트 + 로깅 + 코드 표준화

| 작업 | 상세 | 산출물 |
|------|------|--------|
| 타입 힌트 전면 적용 | 모든 함수 매개변수/반환값 | PEP 484 준수 |

| 에러 처리 강화 | 커스텀 예외 클래스, 상세 에러 메시지 | 디버깅 용이 |
| 코드 검사 | `ruff`, `mypy` 설정 | 정적 분석 |
