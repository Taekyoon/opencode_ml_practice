# B7. 웨이퍼 이미지 — 합성 데이터로 이미지 데이터 다루기

## 학습 목표
- 기존 수치/텍스트와 달리 "이미지"가 입력이 되는 문제를 이해한다
- 웨이퍼맵(wafer map)이 무엇이고 왜 패턴으로 보는지 안다
- 합성 웨이퍼 이미지가 `generate_wafer_images.py`로 어떻게 만들어지는지 확인한다
- 실제 공개 데이터셋(WM-811K)과의 관계를 안다

## 배경 지식

### 이미지 데이터는 수치 데이터와 다르다
지금까지는 `temperature`, `pressure` 같은 **수치**나 프롬프트 **문장**을 다뤘다.
그런데 반도체 공정에서 검사 장비는 웨이퍼를 **촬영**한다. 웨이퍼를 위에서 보면
칩(die)들이 바둑판처럼 배열되어 있고, 각 칩은 검사 결과에 따라 양품/불량으로
표시된다. 이를 "웨이퍼맵"이라고 한다.

```
불량이 "흩어져" 있으면?              불량이 "선"처럼 이어지면?
  ·   ·                              ########
  ·       ·   ·                      ########
      ·   ·                          ########
   particle (파티클)                 scratch (스크래치)
```

핵심 포인트는 **불량이 단독으로 보이는지, 패턴으로 보이는지**다.
공정 장비가 흔들리면 스크래치가 생기고, 이물질이 묻으면 파티클이 생긴다.
따라서 "개별 칩 불량"이 아니라 **웨이퍼맵 이미지 전체의 모양**을 분류하는 것이
실제 공정 문제 파악에 유용하다.

### 이미지 규격
이 프로젝트에서는 간단한 32×32 그레이스케일(회색조) 이미지를 쓴다.

- **0** : 웨이퍼 밖 (원형 마스크 밖)
- **1~15** : 양품 칩 (미세 노이즈)
- **255** : 불량 결함 (긁힘·균열·이물질 점)
- **64~153** : 오염(contamination) 영역 — 반투명 얼룩 (결함 255와 구분)

`src/generate_wafer_images.py`가 이 웨이퍼맵을 **템플릿 + 랜덤 변형**으로 합성한다.
시드가 고정되어 언제 실행해도 같은 데이터가 나온다.

### 클래스 (교육용 균형 분포)
| 클래스 | 비율 | 의미 |
|--------|------|------|
| normal | 50% | 결함이 거의 없음 |
| scratch | 12% | 직선형 긁힘 |
| particle | 12% | 산발적 이물질 점 |
| crack | 12% | 가는 균열 선 |
| contamination | 14% | 넓은 얼룩/오염 |

## 따라하기

### 1단계: 플랜 (생성 스크립트 실행)
이미지도 프롬프트처럼 **합성 생성 스크립트**의 결과물이다.
먼저 생성 스크립트를 실행해 `data/synthetic_wafer.npz`를 만든다:
```bash
python src/generate_wafer_images.py
```

### 2단계: 빌드 (NPZ 내용 확인)
```bash
python - <<'PY'
import numpy as np
d = np.load("data/synthetic_wafer.npz")
print("images:", d["images"].shape, d["images"].dtype)
print("labels:", d["labels"][:10])
print("픽셀 값 종류(일부):", np.unique(d["images"])[:20])
PY
```
`images`는 (2000, 32, 32) uint8 배열, `labels`는 클래스 이름 배열이다.
픽셀 값은 소수 노이즈(1~15)·오염(64~153)·결함(255)이 섞인 연속 분포다.

### 3단계: 검증 (눈으로 보기 — 텍스트로 확인)
터미널에서 이미지를 직접 보긴 어려우니, 각 픽셀을 문자로 출력해 "모양"을 확인한다:
```bash
python - <<'PY'
import numpy as np
d = np.load("data/synthetic_wafer.npz")
idx = np.where(d["labels"] == "scratch")[0][0]
img = d["images"][idx]
for row in img[::2]:          # 2행 건너뛰어 가로로 압축
    print("".join("#" if v > 100 else "." for v in row[::2]))
print("label:", d["labels"][idx])
PY
```
스크래치의 직선 패턴이 눈에 보인다. `particle`, `crack`, `contamination`으로
바꿔보며 패턴 차이를 확인하자.

#### 관찰 포인트
- 각 클래스마다 **패턴이 뚜렷**하다 → 분류기가 잘 배울 수 있다
- 다만 "scratch와 crack"처럼 둘 다 선형이라 **구분이 어려울 수 있다** (이 한계는 I2에서 특징 공학으로 다룸)

### (선택) 4단계: 실제 데이터셋 구경하기
실제 반도체 웨이퍼맵 공개 데이터셋인 **WM-811K**(TSMC 제공, 811K장)를 알아둔다.
- Kaggle: <https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map>
- 라벨 172,950장 중 결함 유형: Center / Donut / Edge-Loc / Edge-Ring / Loc / Random / Scratch / Near-full (+ none=정상)

> 다운로드는 아직 하지 않는다. 이 프로젝트의 기본 파이프라인은 합성 데이터로
> 동작하며, 실제 데이터 활용은 모듈 I에서 `wm811k` 소스로 연결한다.
